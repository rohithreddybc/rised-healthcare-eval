## 0. Why this document exists

A referee observed, correctly, that the manuscript recommends replacement
metrics whose operating characteristics it never measured. The manuscript shows
that under case mix — one shared model, identical coefficients, Bayes-optimal,
perfectly calibrated in every subgroup, differing only in covariate distribution
— every subgroup AUROC-gap procedure flags this perfectly fair model at high
rates (0.92 at a realistic gap, 1.00 at n = 10,000). It concludes that the
equal-AUROC null is the wrong estimand and recommends **subgroup calibration**
and **subgroup net benefit** instead (van Calster 2025; Pfohl 2022;
Benitez-Aurioles).

This document puts that recommendation through the same geometries, the same
seeds and the same draws that indicted AUROC.

## 1. What was run

Every geometry in `recompute/comparators/simulate.py` — the six case-mix
geometries and the seventeen equal-AUROC (simple and composite) ones — at
**1000 simulated datasets**, **B = 999** permutation replicates, seed 42,
inclusion rules `m30` and `ev10`. Identical to the AUROC Type I study
(`recompute/comparators/type1.py`) on every one of those knobs.

The datasets are not merely comparable, they are the same objects: the study
calls the same `simulate.make_dataset(geometry, replicate, seed)` and never
draws its own cohorts, and its permutation stream is seeded exactly as
`type1._one_sim` seeds the incumbent's (`default_rng([seed, rep, 1])`,
`scheme="joint"`). Any difference between the AUROC result and the result below
is the metric and nothing else.

### 1.1 The metrics

| key | quantity | perfect value |
|---|---|---|
| `citl` | calibration-in-the-large: intercept `a` of `logit(P(y=1)) = a + logit(s)` | 0 |
| `mean_cal` | the O−E moment form, `mean(y) − mean(s)` | 0 |
| `cal_slope` | slope `b` of `logit(P(y=1)) = a' + b·logit(s)` | 1 |
| `ece` | expected calibration error, 10 equal-width bins | 0 |
| `ece_null` | ECE of labels redrawn as `y* ~ Bernoulli(s)` — the finite-sample **bias floor** | — |
| `nb_t` | net benefit `TP/n − (FP/n)·t/(1−t)` (Vickers & Elkin 2006) | — |
| `snb_t` | standardised net benefit, `nb_t / prevalence` | — |
| `prevalence` | subgroup event rate — a diagnostic, not a fairness metric | — |

Thresholds are `t ∈ {0.05, 0.10, 0.20, 0.30}`. The case-mix geometries sit at
prevalence 0.20, and a threshold worth acting on lies in a band around the
prevalence: below it the model is dominated by treat-all, far above it by
treat-none. The same set is used for every geometry so the tables are
comparable.

**ECE is never reported without its bias.** ECE is a sum of absolute values and
is biased upward by an amount that grows as bin counts shrink (Nixon et al.
2019; Roelofs et al. 2022). Under the case-mix geometries the score *is* the
true probability, so the true ECE is exactly zero and **every unit of a reported
ECE is estimation bias**. `ece_null` gives that floor per subgroup, and it is
subgroup-specific precisely because the bias is: a subgroup with fewer rows, or
with its score mass concentrated in fewer bins, has a different floor. For the
same reason no standard error is computed for ECE and no studentized test is run
on it — a standard error would invite exactly the test the bias invalidates.

### 1.2 The gap statistic

Per metric, the max over partitions of the within-partition max−min across
admissible levels — **the same functional the AUROC study indicts**, applied to
different per-level numbers.

### 1.3 The three naive tests

| test | construction | has a nominal level? |
|---|---|---|
| `fixed_threshold` | gap ≥ a conventional cut (slope 0.20, CITL 0.20, O−E 0.05, ECE 0.05, NB and sNB 0.05) | no — deterministic screen, the analogue of the manuscript's `fixed_threshold_005` |
| `wald_maxt` | largest studentized pairwise contrast `\|m_i − m_j\| / sqrt(se_i² + se_j²)`, two-sided normal, Bonferroni over pairs | yes, α = 0.05 |
| `permutation` | Monte-Carlo p-value of the gap under joint label permutation, B = 999 — the incumbent's own procedure with the AUROC swapped out | yes, α = 0.05 |

`wald_maxt` is included so the question "what would a naive test's Type I error
be" is answered for a test that is actually reasonable, not only for a
fixed-threshold rule that never claimed a level.

### 1.4 How to read a flag rate

The `flag_means` column of the CSV carries the interpretation row by row, and
the readings must not be averaged together.

* **True subgroup gap is zero** — all simple-null geometries, and *all
  calibration metrics under case mix*. A flag is a Type I error in the ordinary
  sense and the rate should sit at α.
* **True subgroup gap is non-zero** — net benefit under case mix. A flag is not
  a Type I error, because the null is false. It is still a **false alarm about
  fairness**: the model generating the data is the exact conditional probability
  and is unfair to nobody. This is the same reading the AUROC study's case-mix
  rows carry, and it is the reading that decides the question.
* **Composite null** — a per-level strictly monotone score map preserves each
  subgroup's AUROC exactly but does **not** preserve its calibration or its net
  benefit, so those subgroups genuinely differ and a flag is a **true**
  positive. Claiming a zero true gap there would be false, and the code returns
  `None` rather than `0.0` for it.

### 1.5 What makes the truth exact

`replacement.true_case_mix_metrics` computes the population value of every
metric by quadrature — the analogue of `simulate.true_subgroup_auc` — so the
true gaps below carry **no Monte-Carlo error**. Under a case-mix geometry the
score is `p = expit(b0 + L)` with `L ~ N(loc_g, scale_g²)` and `y ~ Bernoulli(p)`,
so within level `g`

```
prevalence_g = E[p]
NB_g(t)      = E[ 1{p >= t} (p - t) ] / (1 - t)
sNB_g(t)     = NB_g(t) / prevalence_g
```

while the true CITL is 0, the true calibration slope is 1 and the true ECE is 0
in *every* level. The quadrature is checked against a 500,000-row Monte-Carlo
draw from the same geometry in `tests/test_replacement_metrics.py`; the headline
finding rests on it, so it is validated rather than asserted.
