# RISED Framework Documentation

RISED evaluates AI decision-support systems across five complementary dimensions before clinical deployment.

| Dimension | What it measures |
|-----------|-----------------|
| **Reliability** | Output stability under semantically equivalent but differently encoded inputs |
| **Inclusivity** | Performance consistency across demographic and clinical subpopulations |
| **Sensitivity** | Behavioral stability under small input perturbations and threshold changes |
| **Equity** | Alignment between model-predicted need and observed clinical need |
| **Deployability** | Operational feasibility: interpretability, explanation faithfulness, latency |
